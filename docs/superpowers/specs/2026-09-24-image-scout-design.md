# Image Scout — approved design

Windows desktop image launcher, approved in conversation on 2026-09-24. Electron with a React renderer. Compact charcoal window, subtle purple accents, minimal controls inspired by the supplied Agentative/Raycast direction. No existing app or server was identified, so the desktop main process acts as the private backend and stores the user's SerpApi key using Windows encryption. No secret reaches the renderer after setup.

Start with a search tab; Enter searches Google Images through SerpApi. Each tab owns its query, loading state, results, error, and request generation. Ctrl+T opens a tab while other requests continue; Ctrl+W closes it; stale responses must not replace newer results. A permanent Saved tab lists local files from both copy and save, with filter and reveal in Downloads. Escape hides the window; a configurable global shortcut (Alt+Space default, fallback Ctrl+Alt+Space) shows it. Closing hides to tray; tray offers Open and Quit.

Each image offers copy, save, and background removal. Copy downloads and writes an actual bitmap to clipboard, and saves in Downloads. Save downloads without clipboard mutation. Names use the search phrase, safe Windows characters, and exclusive file creation: Monkey (1).png, Monkey (2).png. Never overwrite existing files, including concurrent downloads. Store saved metadata locally and atomically. Saved files are PNG normalized from supported downloaded formats; unavailable originals show actionable errors. Background removal uses a local model, downloaded on first use, with progress and transparent preview, then explicit copy/save. Keep UI responsive during model work.

Settings accept a private SerpApi key, shortcut, and show the Downloads path. API key entry is password-masked, never logged, never committed, and encrypted before persistence. Search only occurs on Enter to limit paid requests. Search failures, quota errors, bad keys, download failures, clipboard failures and model failures are shown without leaking credentials. Remote images are untrusted; desktop bridge is narrow, renderer sandboxed, remote navigation denied, downloads bounded, protocols validated.

Validation: meaningful tests for collision-safe names, storage persistence, remote image validation and search shaping; UI tests with a fake bridge for independent tabs and saved/copy flows; packaged desktop smoke checks for launch, encrypted settings, clipboard, and tray lifecycle. Live paid searches need the user's key entered locally. Deliver runnable Windows app plus source and setup instructions.
